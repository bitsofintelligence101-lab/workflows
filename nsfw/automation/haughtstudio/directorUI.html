          How running works
          
    
            
  1. Start the server once: python director_server.py, then open http://127.0.0.1:5000.
    2. 
            
  2. Build your scenes (Export for Future use/edits), press ▶ Run — the server executes the equivalent of this script in-process via MovieDirector.
    3. 
            
  3. The Run status panel streams server logs and movie_manifest.json progress live; media links are served over HTTP by the server.
    4. 
            
  4. ■ Stop is cooperative: the run halts after the current clip finishes (in-flight ComfyUI generations are not killed).
